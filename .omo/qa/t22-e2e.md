## Defects found & fixed BY this E2E (the reason it exists)

1. **PostCSS/BOM build crash** — PowerShell `-Encoding utf8` wrote BOMs into
   package.json files; Vite's PostCSS config scan died parsing them. Stripped.
2. **esbuild bundled into main** — "The esbuild JavaScript API cannot be
   bundled" at runtime. Fixed: main build `rollupOptions.external`.
3. **electron npm shim bundled instead of runtime API** — adding the explicit
   external list REPLACED externalizeDepsPlugin's externals, so `electron`
   resolved to the Node-side getElectronPath shim → instant crash under
   Playwright. Fixed: explicit `external:['electron','esbuild']`.
4. **esbuild unresolvable from out/main** — pnpm doesn't link workspace deps
   into root node_modules; the app manifest (root package.json) now owns
   runtime externals (`dependencies.esbuild`), making direct launches AND
   future electron-builder packaging work on fresh installs.
5. **bootstrap templates missing from out/** — lib build emits only bundled
   JS; added `scripts/copy-main-assets.mjs` to build chain copying
   `templates/*.cjs` next to the bundle (fixes exit-1-in-86ms runs).
6. **TS leaked into engine shells** — analysis snippets are now type-stripped
   (esbuild loader:'ts') when `lang:'ts'` (renderer sends per-file language).
7. **V8 15.x filter drift** — `--print-bytecode-filter=<name>` yields ZERO
   output for eagerly-compiled functions (SFI names empty at dump time).
   Bytecode analysis now uses `--no-lazy` full dump; normalized view locates
   blocks; drift documented in t17/t20/t22.
