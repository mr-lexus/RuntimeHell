## Format-drift discovery (REAL V8 15.x, recorded for parsers in todo 18)

Plan's literal marker `[generated bytecode for function: sum]` matches only
up to V8 ~12. REAL current output (captured during QA, d8-debug canary):

```
[generated bytecode for function: sum (0x027701033b2d <SharedFunctionInfo sum>)]
Bytecode length: 57
Parameter count 1
Register count 5
Frame size 40
   0x14f010000c8 @    4 : 8d 01 00 00       CreateClosure [1:0x... <SFI sum>], FBV[0], #0
   ...
         0x14f0100012a @    2 : 42 03 00          Add a0, EmbeddedFeedback[0]
```

Assertions therefore pin the STABLE prefix + signature opcode
(`/generated bytecode for function: sum \(0x[0-9a-f]+ <SharedFunctionInfo sum>\)/`
and `'Add '`), never the volatile pointer bytes.
