- `apps/main/src/engines/probe.ts` — scripted probe suite executed against
  the EXACT binary with an 8s watchdog and injected executor:
  · liveness gate using the d8-only `print()` global (`[RH_PROBE_OK]`)

  (latest installed version per engine), describe()/list() returning
  {version, binaryPath, capabilities|null, reason}, analyze() dispatch stub
  for todo 17. UI gating contract: capability=false → action disabled with
  reason tooltip; missing binary → "not installed" reason.
- Router/preload surface for enginesList + engineCapabilities lands with the
  analysis drawer wiring in todo 19 (channels already declared).
